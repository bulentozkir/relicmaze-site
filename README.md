# RelicMaze — Official GitHub Pages Website

Official static GitHub Pages showcase for **RelicMaze** — an original room-by-room temple puzzle platformer for Windows (`144` solver-verified chambers across a `12`-floor stepped pyramid, `11` Hidden Sanctums, `9` Meridian Sigils, spectral relics, and `20` languages).

## Structure

- `index.html` — Main showcase page (`v0.0.8` / `rm-native-8`) with procedural Meridian Sky & Astrolabe canvas, animated GIF gameplay trailer (`assets/media/trailer.gif`) + Dual 432 Hz original soundtracks (`relicmaze.mp3` & `relicmaze-phrygian.mp3`) with live Web Audio spectrum visualizer, interactive 144-Chamber Stepped Pyramid & 11-Sanctum explorer, 13-card Illustrated Bestiary (`PositionTraps`, `701 EnemyAudit` & `SwitchAudit`), 50-stone Kabeel spotlight, interactive 14-page *Help* Book plate explorer, 17-page *Legend* showcase with live studio-voiced prologue word-by-word karaoke sync, Astral Veil phase-shift diorama, official logos (`44×44` through `1920×1080`, `128×128`, `703×368`), and 20-language selector (including RTL mirroring for Arabic and Urdu).
- `support.html` — Player Support, system requirements, save file locations (`%APPDATA%\RelicMaze`), controls, and accessibility shortcuts.
- `privacy.html` — Privacy Policy (100% offline play, zero telemetry, zero accounts, local-only saves).
- `copyright.html` — Copyright, originality & provenance notice, plus MIT licences for Godot Engine and .NET.
- `.nojekyll` — Static GitHub Pages marker.
