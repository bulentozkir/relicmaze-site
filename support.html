Player Support & Field Manual

Installation, controls, save files, accessibility shortcuts, and troubleshooting for RelicMaze on Windows.

1. System Requirements & Installation

  • Operating System: Windows 11 or Windows 10 (version 1903 / build 18362 or newer).
  • Architectures: Native x64 and ARM64 packages (MSIX bundle and MSI installers).
  • Network: None required — RelicMaze runs 100% offline.
  • Single-Instance Protection: Launching RelicMaze.exe while already open switches cleanly to the running window instead of opening a duplicate instance.
  • Seamless Upgrades: Installing a newer build replaces the previous installation in place without duplicating shortcuts or deleting save progress.

2. Save Files & Settings Storage

Both the Microsoft Store / MSIX package and the standalone MSI installer write save data and configuration to your real user profile directory:

  • Folder: %APPDATA%\RelicMaze
  • Expedition Save: campaign-save.json (with crash-safe atomic backup campaign-save.json.bak)
  • Settings & Bindings: settings.cfg

Uninstalling RelicMaze leaves your save files intact so you never lose expedition progress. To reset your campaign, choose Delete Expedition Save… on the Title Screen.

3. Accessibility & Quick Shortcuts

  • F9 — Toggle Clear View low-vision high-contrast rendering on/off at any time.
  • F10 — Cycle through the four contrast-audited Clear View palettes.
  • F1 or H — Open the Controls reference card and the illustrated 17-page book Help & Legend.
  • Tab or J — Open the 144-Chamber stepped pyramid Journal.
  • Settings → Accessibility: Scale UI up to 250%, enable Bold Text, Chamber Magnifier, Spoken Narration (via Windows TTS voices or live captions across 20 languages), Reduced Motion, Reduced Flashes, and Timing Assists.

4. Troubleshooting & Contact

No Spoken Voice for Selected Language

RelicMaze uses installed Windows speech synthesis voices. If Windows does not have a voice pack installed for your chosen language, all spoken hints and descriptions automatically appear as readable on-screen captions. You can add additional voices in Windows Settings → Time & language → Speech.

Controller Reconnection

Standard XInput / Windows gamepads work seamlessly alongside keyboard navigation (D-Pad / Left Stick to move, South button to jump, West button to interact, Start to pause). Every key and gamepad button (except F11/F12) can be rebound under Settings → Controls.
